# Полезное

## Команды

- Установка `midicsv` (расшифровка бинарного MIDI в текст):
  ```
  sudo apt install midicsv
  ```
- Расшифровка MIDI в текст:
  ```
  midicsv /mnt/d/a/v2m/data/test.mid
  ```
- Транскрипция аудио в MIDI (из корня рабочей области):
  ```
  basicpitch/build/basicpitch <input.wav> <out dir> [options]
  ```
- Переконфигурация сборки (после перемещения каталогов):
  ```
  cmake -S basicpitch/src/basicpitch.cpp/src_cli -B basicpitch/build
  ```
- Сборка с нуля (после клонирования репозитория): vendor-зависимости upstream
  (onnxruntime и др., ~700 МБ) в репозиторий не включены. Получить:
  ```
  git clone --recurse-submodules https://github.com/sevagh/basicpitch.cpp /tmp/bp
  cp -r /tmp/bp/vendor basicpitch/src/basicpitch.cpp/vendor
  ```
  Затем собрать CLI: `cmake -S basicpitch/src/basicpitch.cpp/src_cli -B basicpitch/build && cmake --build basicpitch/build`.
- Сборка конвертера MIDI → MusicXML (наш инструмент, без зависимостей):
  ```
  cmake -S basicpitch/src/midi2musicxml -B basicpitch/src/midi2musicxml/build
  cmake --build basicpitch/src/midi2musicxml/build
  ```
- Конвертация MIDI в MusicXML (создаёт `test.musicxml` рядом; питч-бенды отбрасываются):
  ```
  basicpitch/src/midi2musicxml/build/midi2musicxml test.mid
  ```
- Сборка нативной библиотеки `libv2m.so` (для Kotlin-приложения; веса модели встроены):
  ```
  cmake -S basicpitch/src/libv2m -B basicpitch/src/libv2m/build
  cmake --build basicpitch/src/libv2m/build
  ```
- Запуск Kotlin-приложения (Compose Desktop GUI; из каталога `app/`):
  ```
  ./gradlew :desktopApp:run
  ```
  Проверка цепочки без GUI: `./gradlew :desktopApp:run --args="--self-test"` (транскрибирует data/test4.wav в /tmp/v2m-selftest/).
- Установка проигрывателя MIDI (timidity), звукового набора GM (fluid-soundfont-gm) и утилит ALSA (запись/воспроизведение):
  ```
  sudo apt install timidity fluid-soundfont-gm alsa-utils
  ```
- Запись с микрофона в WAV (рекомендуется — сразу 22050 Гц, родная частота модели):
  ```
  arecord -f S16_LE -r 22050 -t wav test.wav
  ```
- Воспроизведение WAV:
  ```
  aplay test.wav
  ```
- Прослушивание MIDI (звучит встроенным GM-набором):
  ```
  timidity test.mid
  ```

Примечание: запись по умолчанию (`arecord -f S16_LE -t wav`) даёт 8000 Гц — выше 4 кГц всё теряется (модель использует высоты до ~4.2 кГц), утилита ресемплирует, но отфильтрованное не восстановить. Поэтому записывайте сразу в 22050 Гц.

## Известные предупреждения

- `Schema error: Trying to register schema ... already registered` — безвредное предупреждение ONNX Runtime при создании сессии: системный `libonnxruntime.so` тянет системный `libonnx.so`, оба регистрируют одни и те же схемы. Модель эти операторы не использует (см. `model.required_operators_and_types.config`), результат не влияет. По умолчанию подавлено (утилита молчит); видно при `--verbose`.

## Принципы

Программа обрабатывает звук кадрами, а не «всё сразу». Аудио приводится к моно и частоте 22050 Гц, затем режется на кадры по 256 отсчётов — один кадр ≈ 11.6 мс. Для каждого кадра нейросеть выдаёт вероятность для всех 88 высот (нот) одновременно (0..1 — читайте как «проценты»): вероятность, что высота звучит в кадре, и вероятность, что она начинается именно в этом кадре.

Нота детектируется так: кадр с вероятностью начала (onset) выше порога становится началом ноты; нота длится, пока вероятность звучания в кадрах не упадёт ниже порога. Короткие ноты отбрасываются, а у границ ноты допускается несколько подряд идущих «пустых» кадров — это влияет на то, рвётся ли нота при кратковременных провалах энергии.

Дополнительный «мелодический проход» (melodia trick) ловит ноты без выраженного начала: он берёт остаточную энергию кадров (после основного прохода) и сегментирует её на отдельные ноты (к родительской ноте не приклеиваются; склейка — это --harmonize-merge), используя те же пороги (`--frame-threshold`, `--energy-tol`, `--min-note-len`). Управляется флагом `--melodia-trick` (по умолчанию включён); отключение полезно, если нужны только ноты с чётким onset.

Поэтому пороги задаются в вероятностях 0..1, а длины — в кадрах: 1 кадр ≈ 11.6 мс (11 кадров ≈ 128 мс). Инструмент задаётся номером программы MIDI.

## Ручки (опции CLI)

| Опция | По умолчанию | Назначение | Влияние (примеры) |
|---|---|---|---|
| `--onset-threshold <0..1>` | 0.5 | порог вероятности начала ноты в кадре (0..1; 0.5 = 50%) | < — ловятся все начала, но больше ложных срабатываний <br> > — меньше лишних нот, но шанс потерять тихие/быстрые атаки |
| `--frame-threshold <0..1>` | 0.3 | порог вероятности звучания ноты в кадре (0..1); ниже — нота закончилась | выше — ноты короче (раньше обрываются, отсекаются хвосты); ниже — ноты длиннее и могут сливаться (0.2 — «мягкие» границы) |
| `--min-note-len <n>=1` | 11 | минимальная длина ноты в кадрах (1 кадр ≈ 11.6 мс; 11 ≈ 128 мс) | больше — отсекаются короткие ноты/хрипы (20 — только длинные ноты); меньше — сохраняются стаккато и щелчки |
| `--energy-tol <n>=1` | 11 | подряд идущие «пустые» кадры у границ ноты, которые её не прерывают (1 кадр ≈ 11.6 мс) | больше — ноты не рвутся при кратковременных провалах энергии (вибрато, паузы в звуке); меньше — ноты рвутся чаще (15 — лигато-подобно) |
| `--program <0..127>` | 4 | инструмент MIDI (стандарт General MIDI) | на распознавание не влияет — только тембр воспроизведения (0 — рояль) |
| `--velocity-compress <0..1>` | 0 (выкл) | компрессия динамики velocity (0 — тихие/громкие различимы, 1 — сильная) | 0 — тихие/громкие различимы (test1: 41..114); 1 — динамика выровнена (87..123): удобно слушать голос, но теряется выразительность |
| `--pitch-bends` / `--no-pitch-bends` | включено | питч-бенды (глиссандо между нотами) в выходном MIDI | вкл — вибрато/подъезды как бенды (точнее звук); выкл — ноты строго на хроматической сетке (чище для нотного стана) |
| `--melodia-trick` / `--no-melodia-trick` | включено | мелодический проход: ноты без выраженного onset по остаточной энергии кадров | вкл — ловятся протяжные ноты с мягкой атакой (легато), нот больше; выкл — только ноты с чётким началом, нот меньше |
| `--harmonize-merge <N>=1` | 0 (выкл) | слить соседние фрагменты с разницей ≤ N полутонов (вибрато-дробление) в одну ноту | 0 — вибрато дробит ноту (test1: 46 фрагментов); 1 — слияние в целые ноты (22; test4: ровно 4); 2 — агрессивнее (допускает полутоновые «подъезды»); 3 — до 3 полутонов (риск склеить соседние ноты) |
| `--min-bend <n>=1` | 0 (выкл) | обнулить питч-бенды мельче n бинов контура (1 бин ≈ 33 цента) | 0 — все бенды; 1..2 — убраны мелкие колебания (дрожание), ноты «ровнее» |
| `--global-shift <0..1>` | 0 (выкл) | медианный сдвиг всех нот при глобальной расстройке записи (0..1 — сила) | 0 — выкл; 1 — полная компенсация (тест +25 центов → ровный строй, бенды ≈ +1.3 цента); полезно для расстроенной записи |
| `--mode-snap <0..1>` | 0 (выкл) | подобрать лад (12 тональностей × 6 ладов, допуск 30 центов) и притянуть ноты к ступеням (0..1 — сила; 0.9 ≈ «почти», 1 = ровно; при < 50% попаданий — только сдвиг) | 0 — выкл; 1 — ноты ровно на ступенях лада (test4: C major, 100%); 0.9 — мягче; при < 50% попаданий — только сдвиг |
| `--verbose` | выключено | показывать ход обработки (загрузка, инференс, запись); без него — тишина, ошибки — в stderr | — |
| `--tempo <BPM>` | 0 (авто) | ручной темп (30..300); 0 = авто-детекция (автокорреляция onset, приор 120 BPM) | 0 — автодетекция (test1: 120.2 BPM); 90 — ручной: сетка долей ровно по нему |
| `--quantize <mode>` | off | квантизация ритма: `off`, `auto`, `beat`, `eighth`, `sixteenth` | off — сырой ритм; auto — самая мелкая сетка, объясняющая ≥90% стартов нот (допуск ≤ половины шага сетки); beat/eighth/sixteenth — фиксированное деление |
| `--tempo-tolerance <мс>` | 40 | допуск прижимания стартов/концов нот к сетке | больше — старты/концы сильнее прижимаются к сетке; меньше — ближе к сырому ритму |

## Примеры

- Строгое распознавание атак, без коротких нот:
  ```
  basicpitch/build/basicpitch data/test.wav basicpitch/output --onset-threshold 0.7 --min-note-len 20
  ```
- Другой инструмент (0 — Acoustic Grand Piano):
  ```
  basicpitch/build/basicpitch data/test.wav basicpitch/output --program 0
  ```
- Мягкое распознавание границ нот (лигато):
  ```
  basicpitch/build/basicpitch data/test.wav basicpitch/output --frame-threshold 0.2 --energy-tol 15
  ```
