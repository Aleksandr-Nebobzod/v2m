# Лендинг v2m

Две страницы о приложении: `index.html` (русская) и `en.html` (английская).
Самодостаточный HTML — сборки нет, из внешнего только шрифты Google Fonts.
Разметка, стили и скрипт иллюстрации — внутри файла; переключатель RU/EN — ссылка между страницами.

## Выкладка на http://attplus.in/v2m

В каталог сайта `/v2m` положить:

| файл | откуда |
|---|---|
| `index.html` | этот каталог |
| `en.html` | этот каталог |
| `img/app.png` | этот каталог — снимок окна программы |
| `download/v2m-linux-x64-1.0.0.tar.gz` | `dist/make.sh` → `dist/out/` (43 МБ) |

Ссылки между страницами и на архив — относительные, поэтому адрес сайта в разметке не упоминается.
Каталог `download/` в репозитории пуст: сам архив в него не кладётся, иначе 43 МБ дублировались бы в рабочей копии.

## Обновление версии архива

Имя файла архива встречается в каждой странице 4 раза: кнопка в шапке, шаг 1, команда `tar -xzf`, подвал.
При новой версии заменить имя (и размер, если изменился) во всех местах:

    sed -i 's/v2m-linux-x64-1\.0\.0/v2m-linux-x64-1.0.1/g' index.html en.html

## Что за чем

- Заголовок, описание и ключевые слова — `<title>`, `<meta name="description">`, `<meta name="keywords">` в начале каждой страницы.
- Палитра — токены в `:root`; тёмная тема — в `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`.
- Иллюстрация в шапке — `<canvas id="wave">`, рисуется скриптом в конце страницы по фиксированному зерну и перерисовывается при смене темы.
- Снимок окна — `img/app.png` (790×570, интерфейс русский; на английской странице это указано в подписи).
